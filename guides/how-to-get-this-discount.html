How to get a military discount

Last verification pass: November 18, 2026 (Pacific Time).

Use this page as the pattern for every “how to get this discount” guide we publish. The steps are the same in spirit: start on the official page, verify the way the brand asks, and keep proof of service ready. The details always belong to the brand, not to us.

Before you start

  1. Open the official program page linked from the deal card — not a screenshot from social media and not a code from an expired listicle.
  2. Read who qualifies. Active duty, veteran, retiree, Guard and Reserve, spouse, and Gold Star eligibility are not interchangeable.
  3. See whether the brand uses ID.me, SheerID, a .mil email, an authorization number, or an ID check at the desk or the lot.

Typical verification paths

  • ID.me or SheerID. Create or sign in to the brand’s account first, then complete the verification those services request. Use a personal email unless the brand asks for a .mil address.
  • A rate code at booking. Some hotel programs (for example, Wyndham’s SML) require a code plus ID at check-in. Enter the official code exactly as the brand publishes it.
  • Authorization numbers. Auto programs such as GM and Jeep often email a number you must give the dealer before delivery. A late number can cost you the offer.
  • In-person ID. Hotels, rental counters, and airline desks still ask for a military, veteran, or government ID even if you booked online.

At purchase or check-in

Bring the same ID the official page names. If a rate disappears at the desk, ask the property to compare it with the official military or government rate — and keep your confirmation. We cannot honor a rate on a brand’s behalf.

This is a template. Replace the steps with the official instructions for a single program when you publish a brand-specific guide, and stamp the date you re-checked that page.
